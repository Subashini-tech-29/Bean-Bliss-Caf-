# Bean Bliss Café

A responsive frontend café ordering application built with HTML, CSS and vanilla JavaScript.

## Run in Replit
1. Upload/extract this project.
2. Open `index.html`.
3. If Replit asks for a run command, use any static HTML server available in your workspace.

## Main features
- Customer registration/login
- Menu search, category filters and sorting
- Favorites
- Shopping cart
- Coupons
- Checkout with dine-in/takeaway/delivery
- Demo payment choices
- Order history and tracking
- Reorder
- Reviews/contact UI
- Admin dashboard
- Food and order management
- LocalStorage persistence
- Dark mode
- Responsive mobile layout

Note: payment and map are intentionally demo/frontend features; no real payment gateway or backend is connected.
