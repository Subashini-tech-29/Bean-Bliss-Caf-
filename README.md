# ☕ Bean Bliss Café

**Bean Bliss Café** is a modern, responsive online café food ordering and management website built using **HTML, CSS, and JavaScript**.

The website provides a complete café experience for customers, including browsing the menu, searching for food, adding items to a cart, placing orders, tracking orders, and managing favorites. It also includes an admin dashboard for managing food items, customers, and orders.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Open the downloaded project folder in **Visual Studio Code**.

### 3. Install Live Server

In VS Code:

**Extensions → Search "Live Server" → Install**

### 4. Run the Website

Right-click on:

```text
index.html
```

Select:

```text
Open with Live Server
```

The Bean Bliss Café website will open in your browser.

## 💾 Data Storage

This project uses **Browser LocalStorage** to store demo data such as:

* User accounts
* Login information
* Cart items
* Favorite items
* Orders
* Food menu data
* Coupon information
* Admin-related data

Because LocalStorage is used, this project does **not require a backend server or database** for the current demo version.
